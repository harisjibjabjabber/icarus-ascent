# Best-quality community VRM heroine candidates (2026-10-31)

Contact sheet: `art/concepts/best-heroine-contact-sheet.png`.
- Row A: models tested in our scene (no login needed).
- Row B: VRoid Hub preview images of the best models that need a pixiv login to download.

Thumbnails are in `art/candidates-best/thumbs/` and in-scene shots in `spikes/vrm-character/shots/best/`. The spike has a new `cam=portrait` view; it frames VRM0 models from the front.

Method: I searched the VRoid Hub public API (~3,250 downloadable models across 29 keywords). I kept only models whose licence panel says all of the following:
- modification allow
- redistribution allow
- personal commercial use = profit
- avatar use = everyone
- not R-18 / adult

Then I excluded:
- school uniforms and student or child-coded characters
- swimwear, bunny and lingerie
- fan models of other IP (Genshin, Wuthering Waves, Blue Archive, Miku and so on)
- animals and robots

and judged the rest by eye. I also checked Sketchfab (public API), Booth and GitHub mirrors.
**VRoid Hub, Booth and Sketchfab downloads all need a login.**

## Rejected (licence or content)

- **Booth 黒曜/Kokuyou (6666669):** "データそのものの再配布または販売" is prohibited, which conflicts with serving the file in a web game.
- **Many VRoid Hub favourites** (e.g. Elsie Estuary edits): non-profit only or redistribution disallow.
- **Genshin, Wuthering Waves and Blue Archive fan models:** third-party IP.
- **Tovie / AiRu swimwear and bunny sets:** fetish-adjacent.
- **β AvatarSample_1/2, Sendagaya Shino and the Ao "school" outfits:** students.
- **AvatarSample_C:** male.
- **"Model 6" fairy (鷲羽あずさ):** 140 cm, child-sized.
